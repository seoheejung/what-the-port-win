간단한 시작.

Windows 10/11 x64 · .NET Framework 4.8 · 관리자 권한 불필요.

포터블 실행

  1. Windows ZIP 다운로드 후 압축 해제.
  2. 앱·Core DLL·설정 파일·폰트 폴더를 함께 유지.
  3. WhatThePort.exe 실행 후 개발 서버 시작.
  4. 트레이의 점 격자 아이콘 클릭 또는 Ctrl + Alt + P.

코드 서명이 없는 로컬 테스트용 빌드입니다. 파일 출처 확인을 위해 SHA-256 체크섬을 제공하며, 체크섬 자체가 배포자 신원을 보증하지는 않습니다.

언어와 보호 항목

기본 언어는 한국어입니다. 설정 → 언어 / Language에서 한국어·English 선택 후 설정 저장. 영어 화면에서는 Settings → Language → Save preferences.

보호됨 표시는 이 앱·상위 프로세스 또는 터미널·에이전트·시스템·DB·컨테이너에 대한 종료 방지입니다. 체크박스가 비활성화되며 상태의 도움말에서 이유를 확인할 수 있습니다. wmux·cagent·Docker도 보호 대상입니다.

서버 본체 종료 후 하위 프로세스만 종료에 실패할 수 있습니다. 포트가 닫히면 목록에서 사라지며, 일부 종료 안내와 종료 결과 상세에서 성공·실패 및 프로세스별 오류 확인이 가능합니다.

프로젝트와 세션 연결

서버 상세 → Link session & preview에서 폴더·에이전트·정확한 세션 ID·Vercel 미리보기 URL 등록. 세션 재개에는 해당 CLI 설치와 로그인이 필요합니다.

Session: Codex는 연관 프로세스 표시입니다. 실제 세션 연결 완료를 뜻하지 않으며, 정확한 세션 ID의 별도 등록이 필요합니다. 미리보기는 등록된 https://….vercel.app 주소 열기만 지원합니다.

터미널에서 조회

.\wtp.exe list
.\wtp.exe list --json
.\wtp.exe list --all

프로젝트 링크 등록 예시:

.\wtp.exe link --port 3000 --folder C:\dev\my-app --agent codex --session YOUR_SESSION_ID

YOUR_SESSION_ID는 실제 ID로 교체할 명령 예시입니다. 같은 폴더·포트의 링크 레코드는 교체되므로, 세션과 미리보기를 함께 유지하려면 같은 명령에 모두 입력해야 합니다.

종료와 자동 정리

먼저 WhatThePort.exe --demo에서 흐름을 확인하세요. 실제 모드에서는 종료해도 되는 자체 테스트 서버만 선택해 동작을 확인하세요. 종료는 TerminateProcess 기반이며 저장·정리 훅을 보장하지 않습니다.

자동 정리는 기본 Off입니다. Ask 또는 Automatic에서 연속 관측된 idle 서버만 후보가 됩니다. 보호·경고 서버는 자동 종료 대상에서 제외됩니다.

서버가 보이지 않을 때

기본 필터는 개발 런타임입니다. Show all user listeners 또는 Settings의 전체 리스너 옵션으로 사용자 정의 실행 파일을 포함할 수 있습니다. wmux·디버거·에이전트의 내부 포트도 함께 표시될 수 있으므로, 현재 작업 중인 앱은 종료 시험에서 제외하세요.

환경별 제약

  • Windows 네이티브 TCP 대상. UDP, WSL·Docker 내부 PID·자원, 다른 사용자의 프로세스 상세 미지원.
  • Windows 알림 설정·집중 지원에 따른 배너 미표시 가능.
  • 다중 모니터 위치 저장 검증 완료. 장시간 자동 정리는 별도 실환경 확인 필요.
  • 한국어·영어 UI 지원. 설정 → 언어 → 설정 저장으로 전환. 서버 재시작·자동 업데이트·TUI·PR 연결 미구현.

접근성과 개인정보

앱의 아이콘 버튼·입력 필드에 Windows UI Automation 이름 제공. 차트의 키보드 탐색과 텍스트 설명, 메시지의 live region 적용. 웹 페이지의 건너뛰기 링크·키보드 탭·이미지 대체 텍스트·모바일 메뉴 제공. 실제 Narrator/NVDA 음성 출력을 포함한 완전한 적합성 인증은 미실시.

이 페이지는 계정·쿠키·분석 SDK·폼·외부 글꼴 없이 동작하는 정적 페이지입니다.
